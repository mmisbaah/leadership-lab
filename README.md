# Leadership Lab

An interactive guide for a one-day leadership training course for working adults. It covers nine sessions across Self, People and Performance, each with outcomes, a simple model, a group activity, a decision scenario and a private reflection box. Progress and notes are saved in the browser.

Plain static site, no build step. Open `index.html` through any static server, e.g. `python3 -m http.server`, then visit http://localhost:8000. Lesson content lives in `lessons.js`.
