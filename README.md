# Leadership Lab

An interactive guide for a one-day leadership training course for working adults: nine sessions in five phases (Self, People, Performance, Integrate, Apply). Each session has a facilitator plan with suggested timings, class slides with a quick check, a decision quiz and a private notes page. A course plan lays the day out from 09:00 to 16:00. Participants sign in, and their answers, notes and completed sessions are saved to their account.

The look follows the Instructor Guide (training-guide.mellowpilot.com): neumorphic light theme and navy dark theme, Barlow Condensed and IBM Plex fonts served from `public/assets/fonts`, styles in `public/css/app.css`.

Plain static site, no build step. Open `index.html` through any static server, e.g. `python3 -m http.server`, then visit http://localhost:8000. Lesson content lives in `lessons.js`.
